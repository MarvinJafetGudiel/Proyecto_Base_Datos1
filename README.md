# MAGIS-AUTO

## Sistema de Gestión Vehicular

Este es nuestro proyecto final del curso de Bases de Datos I.

### Descripción

MAGIS-AUTO es una aplicación web que hicimos para administrar los créditos destinados a la compra de vehículos nuevos en el departamento de Guatemala.

El sistema permite registrar clientes, referencias personales, vehículos, vendedores, fiadores, créditos y pagos. También contará con consultas y reportes financieros para hacer mas fácil el control de las operaciones de la empresa.

### Tecnologías

- SQL Server 2022
- Node.js
- Express.js
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Git y GitHub

### Funcionalidades principales

- Gestión de clientes y referencias personales.
- Registro de vehículos y garantías.
- Administración de vendedores y fiadores.
- Emisión de créditos vehiculares.
- Generación de planes de pago.
- Registro de pagos completos y parciales.
- Consultas y búsquedas de información.
- Generación de 20 reportes financieros.

### Objetivo

Desarrollar una aplicación web que nos permita aplicar los conocimientos adquiridos en el curso de Bases de Datos I, utilizando una base de datos relacional, procedimientos almacenados y una API para realizar las operaciones.
